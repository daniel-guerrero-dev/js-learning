Variable declaration is done with the keyword `let`

you can declare empty variables and declare their values later or declare them in one line:

```js
    let name;
    name = Daniel;

    let number = 5;
```

camelCase is the standard, variable names can't start with numbers

constants are declared with the keyword `const`

The standard practice is to use all uppercase for naming constants

```js
    const THIS_IS_A_CONSTANT = 500;
```
